# قناة الدروبي

تطبيق أندرويد وموقع لأخبار «قناة الدروبي».

- كل تعديل يُرفع إلى `main` يبني ملف APK جديدًا وينشر الموقع تلقائيًا.
- رابط تحميل آخر نسخة: https://github.com/www774475437-svg/aldroubi/releases/latest/download/aldroubi.apk
- الموقع: https://www774475437-svg.github.io/aldroubi/

الأخبار الحالية نماذج لعرض شكل التطبيق، وروابط الحسابات والبث تُضاف في `lib/update.dart`.
